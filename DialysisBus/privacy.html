Site policy

Privacy

This Phase 1 explorer is a static, read-only site. It has no user accounts, patient information, analytics tracker, advertising tracker, or application database.

Location and search

Location access occurs only after you select “Use current location” and approve the browser prompt. The site uses the result to move the map and does not save or transmit it to an application server. Searches that match a published facility city, ZIP code, address, or name remain in the browser. Other searches are sent directly from your browser to Google Maps services for the active interaction.

Browser storage

Shared analysis state is stored in the page URL. If a local user enters a Google Maps browser key, the key may be retained in that browser’s local storage until “Forget key” is selected. The GitHub Pages site uses its published browser key instead.

Third-party services

The basemap and arbitrary location search use Google Maps Platform. Street-level map views request transit stops for the visible geographic bounds from the USDOT/BTS ArcGIS service. Those services are subject to their respective privacy terms. CMS facility and Census-geocode records are served from the published site snapshot.

Feedback contact

Privacy feedback may be submitted through the repository’s GitHub issue tracker. Do not include patient or other sensitive information.
