Accessibility statement

Accessibility

The project targets WCAG 2.2 AA for the non-map interface. Controls are keyboard accessible, focus is visible, layer changes are announced, reduced-motion preferences are respected, and analytics have text and table equivalents.

Alternatives to map exploration

The Analytics tab provides a sortable table on larger screens and cards on smaller screens. Broad national results are capped in the visible table for performance; state selection, map navigation, and filters narrow the population, while CSV export contains the complete current filtered result with provenance fields.

The center-distance heatmap is optional and supplementary. Its legend provides text labels for all five distance bands and the current green and red distance endpoints; when individual facility markers are visible, their descriptions also state the nearest-other-center distance. Color is not the only legend cue.

Known limitation

Third-party map tiles and controls have accessibility characteristics governed by Google Maps Platform. The map is supplementary; it is not the only way to reach facility results.

Feedback

Accessibility feedback may be submitted through the repository’s GitHub issue tracker. Include the page, control, browser, and assistive technology involved, but do not include patient information.
